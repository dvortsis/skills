# Skills

A collection of Agent Skills for AI coding assistants and agents.

## Skill Collections

- [**UI Design Skills**](./ui-design-skills/README.md): 15 subject-specific Agent Skills for building, polishing, and reviewing modern application interfaces and data visualizations.
- [**Documentation Skills**](./documentation-skills/README.md): 5 Agent Skills that build slide decks, Word/PDF documents, training, forms, e-learning and GitHub setup guides in the brand of the project they run in, each behind a lint gate.
